# Changelog

## 1.2.2

- Requires OctoPack 1.7.2.
- Added measured arm and lantern contact profiles for portable backpacks.
- Matched dropped arm and lantern visuals to the saved collision pose.
- Kept light, wisp, and shadow height aligned with saved lantern geometry.
- Added bounded contact metadata repair for older dropped packs.
- Retained existing artwork, textures, sounds, recipes, and configuration defaults.

## 1.2.1

- Restored F9 as the mount/left-hand carrying toggle.
- Set default lantern physics drag to 0.6.
- Deferred the belt hook and removed its model, recipe, mount behavior, and position editor from the active release.
- Retained portable-pack cargo, arm, and lantern support.

## 1.2.0

- Added saved lantern and arm attachments to portable backpacks.
- Added stored-fuel lighting, Wisp mist clearing, and passive aura support for dropped or displayed packs on owning, loaded clients.
